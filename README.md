# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

- welcome.py: contains the `welcome` function that returns a personalized greeting for each student name.
- toolbox.py: contains the `double`, `is_pass`, and `greet` functions used to perform simple calculations and greetings.

The hardest function to write was `greet` because it needed to combine a default argument with string formatting while still producing the exact required output. It also required careful attention to punctuation and optional parameter behavior.
